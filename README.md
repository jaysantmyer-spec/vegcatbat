# Handball Oracle

Win / draw / margin / total predictions for club handball (Bundesliga, Starligue, Liga ASOBAL, EHF Champions
League and more), priced against DraftKings and the wider market. Same learning engine as the UFC and TT Elite
oracles: leak-free walk-forward features, logreg + gradient-boosting ensemble (XGBoost / LightGBM / CatBoost
when available) blended with Hedge weights, temperature calibration, a pre-match ledger that grades itself.

See DEPLOY.md to set it up.
